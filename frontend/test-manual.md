# 手动测试执行记录

## 测试环境准备

### 1. 启动后端服务

```bash
# 在项目根目录
mvn spring-boot:run
```

**验证**: 访问 http://localhost:8080/api/v1/questionnaires/1/render 应返回JSON数据

### 2. 启动前端服务

```bash
# 在 frontend 目录
cd frontend
npm install  # 如果还没安装依赖
npm run dev
```

**验证**: 访问 http://localhost:3000 应显示首页

### 3. 数据库准备

确保已执行初始化脚本：
```bash
mysql -u root -p smart_survey < smart_survey_init.sql
```

**验证**: 数据库中应有问卷ID为1的测试数据
