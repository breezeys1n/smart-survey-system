# 智能问卷与调查系统 - 开发文档

## 项目概述

智能问卷与调查系统是一个功能完整的问卷创建、发布、收集和分析平台。系统支持多种题型、逻辑跳转和数据可视化分析。

### 核心价值
- 超越简单的问卷，加入逻辑跳转和数据洞察
- 动态表单引擎与基础数据可视化
- 支持问卷设计、发布、填写和统计分析全流程

## 技术栈

### 后端
- **框架**: Spring Boot 4.0.0
- **数据库**: MySQL
- **ORM**: Spring Data JPA
- **Java版本**: 17
- **构建工具**: Maven

### 前端（待开发）
- **框架**: React

- **图表库**: ECharts 或 AntV G2

## 数据库设计

### 核心表结构

1. **questionnaire** - 问卷表
   - id: 主键
   - title: 问卷标题
   - description: 问卷描述
   - create_time: 创建时间
   - status: 状态（0=草稿, 1=发布中, 2=已结束）

2. **question** - 问题表
   - id: 主键
   - questionnaire_id: 所属问卷ID
   - content: 问题内容
   - type: 题型（1=单选, 2=多选, 3=文本）
   - question_order: 问题顺序

3. **option_item** - 选项表
   - id: 主键
   - question_id: 所属问题ID
   - option_text: 选项文本
   - option_order: 选项顺序

4. **user_response** - 用户提交记录表
   - id: 主键
   - questionnaire_id: 问卷ID
   - responder_ip: 答题人IP
   - submit_time: 提交时间

5. **answer_detail** - 答案详情表
   - id: 主键
   - response_id: 提交记录ID
   - question_id: 问题ID
   - selected_option_ids: 选中的选项ID（多选用逗号分隔）
   - text_answer: 文本答案

## API 接口文档

### 问卷相关接口

#### 1. 获取问卷详情（用于填写页面）
```
GET /api/v1/questionnaires/{id}/render
响应: Questionnaire 对象（包含问题和选项）
```

#### 2. 提交问卷答案
```
POST /api/v1/questionnaires/{id}/submit
请求体: {
  "questionId1": "optionId1",
  "questionId2": ["optionId2", "optionId3"],
  "questionId3": "文本答案"
}
响应: "提交成功！感谢参与。"
```

### 统计分析接口

#### 1. 获取单个问题统计
```
GET /api/v1/statistics/question/{questionId}
响应: {
  "questionId": 1,
  "questionContent": "问题内容",
  "type": 1,
  "statistics": {
    // 根据题型返回不同的统计数据
  }
}
```

#### 2. 获取问卷完整分析
```
GET /api/v1/statistics/questionnaire/{id}/full-analysis
响应: {
  "summary": {
    "totalResponses": 10,
    "totalQuestions": 5
  },
  "questionsAnalysis": [
    {
      "questionId": 1,
      "questionContent": "问题内容",
      "type": 1,
      "statistics": {...}
    }
  ]
}
```

## 开发环境配置

### 后端环境
1. JDK 17+
2. Maven 3.6+
3. MySQL 8.0+
4. IDE: IntelliJ IDEA / Eclipse

### 数据库配置
1. 创建数据库：
```sql
CREATE DATABASE smart_survey CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. 修改 `application.properties` 中的数据库连接信息

3. 运行初始化脚本 `smart_survey_init.sql`

### 启动后端
```bash
mvn spring-boot:run
```

后端服务默认运行在: `http://localhost:8080`
